# Nigerian-E-commerce-Data-Analysis-
This analysis provides insight about the NIgerian E-commerce Market showing trends and top perfroming products

Title:E-commerce Performance Intelligence &

Revenue Optimization for Strategic Market Expansion — Nigerian Case Study

Project Overview This project presents an in-depth analysis of the Nigerian E-commerce market, exploring total revenue from each region, sales trend, customer behaviour and product performance.The aim is to extract actionable insight that can help businesses optimize operations and make data-driven decisions

Objective

Analyze sales data to identify top-performing products, regions and branch
Dataset Source: [Kaggle public data,https://www.kaggle.com/datasets/babajidedairo/nigerian-ecommerce-sales-dataset?utm_source=chatgpt.com]

Features include: 'Order ID', 'Branch Location', 'Branch Name', 'Business Name', 'Is Deleted', 'Item ID', 'Item Name', 'Item Price', 'Order Item Number', 'Item Status', 'Packed Quantity', 'Quantity', 'Total Price', 'Order Date', 'Order Region', 'Order Local Area'

Data Processing Steps

EDA analysis
Handled Missing Data
Tools & Technique Python : Pandas, Numpy, Seaborn, Matplotlib, pyplot Jupyter Notebook : For analysis and Visiualization

Key Insights

Key Insights Summary – Nigerian E-commerce Analysis

Total Revenue: ₦1.78 billion generated during the analyzed period.

Revenue by Order Status: 'Delivered' orders dominate revenue (₦1.23B, 68.8%), while 'Cancelled' orders contribute significantly (₦493.7M, 27.7%). Other statuses have minimal impact.

Monthly Revenue Trend: Shows an upward trajectory, indicating business growth, though data covers only a few months.

Top Products: High-demand consumer goods like "Milo Sachet 20g," "Knorr Chicken," and "Maize" drive revenue.

Branch & Regional Performance: Lagos branch and region lead in revenue (₦1.74B and ₦1.58B respectively), highlighting Lagos as a key market.

Order Volume vs. Value: 'Delivered' orders are fewer but higher in average order value (₦1.16M) compared to 'Cancelled' orders (₦332K), which are more numerous but lower in value.

Regional Product Preferences: Product popularity varies by region, e.g., "Milo Sachet 20g" tops in Lagos and 'Unknown,' while Ogun favors "Milo 20g" and "Milo Sachet 20g."

Branch & Region Trends: Monthly revenue data by branch/region provides insight into location-specific performance.

Takeaway: Focus on reducing cancellations, leveraging Lagos as a key market, and tailoring product offerings to regional preferences to drive growth.
